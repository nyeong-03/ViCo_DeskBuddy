모닝 데스크 비서 — 첫 Windows 앱

실행
1. '모닝 실행.cmd'를 더블클릭하세요.
2. 화면 오른쪽 아래에 작은 위젯이 뜹니다. 제목 표시줄을 끌어 위치를 옮길 수 있습니다.
3. '+ 추가'에서 날짜, 시, 분, 알림 시점을 각각 고르세요. 분은 00~59분 중 선택할 수 있습니다.
4. 일정은 이 폴더의 morning-reminders.txt에 바로 저장되어 앱을 껐다 켜도 남습니다.
5. 일정을 선택한 뒤 '수정'을 누르거나 더블클릭하면 내용을 고칠 수 있습니다.

현재 되는 것
- 다른 창 위에 유지되는 작은 데스크톱 창
- 일정 추가, 삭제, 로컬 저장
- 정한 시각 전에 Windows 알림 표시
- 연노란 얼굴과 검은 눈·입의 심플 스마일
- 화면 배율에 맞춘 선명한 글꼴과 작은 위젯 크기

아직 없는 것
- Slack, Teams, 메일, 캘린더 계정 연결
- PC를 끄거나 앱을 종료한 동안의 알림
- 시작 프로그램 등록과 설치 파일

Windows 기본 .NET Framework를 사용하는 앱 파일입니다. 설치 프로그램이나 계정 연결은 없습니다.
